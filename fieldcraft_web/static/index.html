How Fieldcraft works

An AI coding agent, driven through a governed develop→verify→iterate loop, with every step recorded as an event — so the run is auditable, resumable, and measurable.

Agents and judges are swappable behind one interface; the engine and event log don't change. Because the run is the log, it can pause for human review and resume after a restart, and the measurement layer reads the same events — no separate instrumentation.
